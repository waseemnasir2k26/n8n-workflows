# Episode 07 — Shared Inbox Router (Drafts Only)

A shared inbox, sorted before a model ever reads it. A deterministic rules router
(known-client allowlist, spam heuristics, regex intents) handles the mail it can call
outright; only the leftover residue reaches one LLM node, which classifies it (lead /
technical / spam / existing_client) and drafts a reply. On a 13-row test set we wrote
ourselves — our own inbox was too new to measure, so we disclose the test set instead
of claiming a real-mailbox number — rules cleared 12 of 13 messages (92.3%), above the
60%-or-more ship gate; only one message needed the model. THE WORKFLOW HAS NO SEND
NODE. The only write it can make is a mailbox label, gated behind a whitelist that
throws on any other shape, and that node ships disabled in this recording. Every
draft waits in a Postgres review table for a person to send it.
