# Episode 06 — Meta Ads Circuit Breaker

We built a kill switch. It watched our own ad set lose $70.15 and never fired. We
already had a breaker running in production, but the rule lived at the campaign
level and needed 40 clicks to trip; the campaign only saw 32, so it never noticed the
ad set that actually lost the money. This n8n workflow scopes the same idea to the
ad set instead. A 15-minute poller reads ad-set insights through the Meta Marketing
API and checks them against caps held in an n8n Data Table, not in code, so the
numbers can change without touching a node. Zero LLM nodes run in this workflow, so
the spend cap is structurally $0. The only write the workflow can make is a single
status change on one ad set, built from fixed constants and thrown on any other
shape, so it cannot raise a budget, change bidding, or touch targeting. Account and
campaign ids are masked before anything is stored, logged, or shown on screen; this
is our own ad set, not a client's. The Schedule Trigger sits on the canvas, disabled,
as the swap point for a real 15-minute cadence; the recorded run is one manual
execution, in dry run — the breaker decided, no write was sent.

We built a kill switch. It watched our own ad set lose 70 dollars and never fired.

We ran our own ad set for lead generation. It spent $70.15 across 982 impressions and
44 clicks, and it booked exactly zero leads, sitting ten dollars past the cap we
would have set for it. We already had a breaker running in production. It never
fired, because the rule lived at the campaign level and needed 40 clicks to trip; the
campaign only saw 32. A rule can be technically correct and still miss the exact loss
it was built to catch.

So we built a second one, scoped to the ad set instead of the campaign. It reads
insights every 15 minutes, checks them against caps sitting in a data table instead
of buried in code, and the only write it can ever make is a pause, built from fixed
constants that throw on anything else. No budget change, no bidding change, no
targeting change. Every account and campaign id gets masked before it is stored or
shown, because this is our own account, not a client's.
