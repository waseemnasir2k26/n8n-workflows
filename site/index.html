Import in 4 steps

JSON to running in under a minute

  1. Open the workflow folder on GitHub and copy the raw workflow.json.
  2. In n8n, open a blank canvas and press Ctrl/Cmd + V (or Menu → Import from file).
  3. Replace every credential marked REPLACE_ME with your own.
  4. Run once manually, then toggle Active.
